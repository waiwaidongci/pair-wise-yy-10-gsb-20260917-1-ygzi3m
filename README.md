# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用，完全离线，数据保存在浏览器 localStorage。

## 排产（新增）

打开页面即看到「未来七天排程」，沿用现有作品数据自动生成：

- 每件未交付作品按 **贴线进度 → 两天阴干 → 一天上金粉** 推算排程与可完成日期（贴线按每天约 50% 进度估算；录入的阴干日期作为最早可阴干日）。
- 产能约束：**每天最多两件阴干、一件上金粉**，排程自动顺延，不超载。
- 优先级：**已超期件 > 缺陷件 > 交付日期早**，新排/重排时生效；「全部重排」按钮可按此规则重排全部未交付作品。
- 看板卡片和作品详情中显示各自的排程；无法按期交付的作品标红「超承诺 N 天」。

## 插单与冲突

- 「新增作品」即插单：现有已承诺订单的排程槽位全部锁定，新单只占用剩余产能，**不会让任何已承诺订单更晚**。
- 若新单无法按承诺交付，弹出冲突提示，显示**原承诺日期、最早可完成日期和冲突原因**（哪几天阴干/上金粉产能被谁占用），由负责人选择「仍然加入（保留原承诺）」或取消——**绝不静默改期**。
- 「承诺与冲突」列表持续展示所有超承诺作品及其原因，交付日期始终保持原承诺。

## 原有功能（保持不变）

- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付；状态流转会增量重排受影响的作品。
- 今日待阴干、缺陷作品、最近交付三类列表；可记录断线/翘线、查看作品详情。
- 支持主题/状态筛选、交付排序、JSON 导出（导出格式不变）。
- 作品数据（`zfl42Works`）与排程结果（`zfl42Schedule`）均持久化，刷新页面后排程保留。
