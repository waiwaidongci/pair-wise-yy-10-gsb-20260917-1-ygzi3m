# zfl-42 小型漆线雕工坊管理（含离线排产）

独立静态前端应用，直接打开 `index.html` 即可使用，数据保存在浏览器 localStorage，无需联网、无需后端。

## 排产规则

- 每件作品按 **贴线进度 → 两天阴干 → 一天上金粉 → 交付承诺** 排出未来七天。
- 贴线进度按每日约 25% 估算完工日；状态已到「待阴干」的作品当日即可入阴干。
- 容量约束：阴干连续两天、每天最多 **2 件**；上金粉每天最多 **1 件**。
- 优先级：**超期件 → 缺陷件 → 交付承诺最早 → 贴线进度高**。
- 今日状态为「上金粉」的在制件锁死当天金粉位，任何排程不能撞车。

## 插单承诺保护

- 急件插单只允许使用当前排程的空余工位，**不会移动任何已承诺订单**。
- 排不进（工艺时间不足 / 工位已满）时：作品保留在冲突区，明确显示**原承诺交付日**和**冲突原因**（哪一天、哪个工位、被哪件占用），绝不静默改期。
- 腾出工位或完成在制件后，可在冲突提示上一键重试。
- 卡片上的「前移一天 / 后移一天」是手工调整：受贴线完工时间、容量、承诺交付日三重校验，不满足即拒绝并说明，数据不变。

## 持久化

- 自动排程落库后即视为承诺；手工调整、插单结果刷新页面后保留。
- 已过期未流转的旧锁定计划会单独标红提示，由负责人决定是否重排，系统不自动改期。
- 「重新自动排程」按钮需二次确认，才会清除手工/插单锁定整体重排（插单仍严格校验，排不进退回冲突区）。
- 旧版本保存的作品数据首次打开自动补排，台账字段不受影响。

## 原有功能（保持可用）

- 新增作品：胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷、交付日期、备注。
- 四列工序看板（贴线中 / 待阴干 / 上金粉 / 待交付）与状态流转、缺陷记录、作品详情。
- 今日待阴干、缺陷作品、最近交付三个快捷列表。
- 主题筛选、状态筛选、按交付/阴干排序。
- localStorage 持久化与 JSON 导出（含排产计划）。
